## 📥 Download

Every production is published in the [**Releases**](https://github.com/ap3demak-rgb/Sandefjord_demos/releases) tab.
Each demos contains the executable (`.exe`) or a video (`.mp4`).

## ▶️ Running a demo

1. Download the `.exe` from the release you want.
2. Double-click it. If a release comes as a `.zip`, extract it first and keep all files in the same folder.

Demos run in real time on **Windows 10/11** with an up-to-date graphics driver.
On Linux you can try [Wine](https://www.winehq.org/) / Proton (`wine demo.exe`).
If your machine can't run a demo, or you just want a quick look, watch the `.mp4` capture instead.

## ❓ FAQ

**My antivirus flags the exe. Is it safe?**
Small intros are compressed with executable packers (Crinkler, kkrunchy, UPX…), which many antivirus engines mistake for malware. This is a well-known false positive in the demoscene. You can check any file on [VirusTotal](https://www.virustotal.com/).

**The demo shows a black screen or crashes.**
Update your graphics drivers, and make sure the demo runs on your dedicated GPU if you have several.

**Where is the source code?**
It is not published. This repository only contains this README and the license; the demos are in the [Releases](https://github.com/ap3demak-rgb/Sandefjord_demos/releases).
